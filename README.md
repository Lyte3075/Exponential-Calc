# Exponentia Calculator

An advanced, responsive, single-file calculator with scientific, graphing, statistics, matrix, equation-solving, conversion, finance, programmer, date/time, constants, themes, history, and import/export features.

## 🚀 Live Demo

**[Open Exponentia Calculator on GitHub Pages](https://lyte3075.github.io/Exponential-Calc/)**

## 📦 Repository

[Lyte3075/Exponential-Calc](https://github.com/Lyte3075/Exponential-Calc)

## ✨ Features

- Standard and scientific calculator
- Graphing calculator
- Statistics tools
- Matrix operations
- Equation solver
- Unit converter
- Finance calculator
- Programmer / bitwise tools
- Date & time calculations
- Mathematical and physical constants
- Calculation history
- Memory functions
- Multiple themes
- Import/export settings
- Responsive mobile and desktop layout
- No external libraries required

## 🛠️ Run Locally

Open `index.html` in any modern web browser.
